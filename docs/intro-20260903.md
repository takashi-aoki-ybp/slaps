# Opening playback gate — v3.44

## Scope

The user closed the central YouTube icon investigation based on their current
production observation and asked to change only the opening. No report is sent
to YouTube. No central-button or iframe-parameter workaround is included here.

Replace the old unconditional 1.3s fade / 1.75s removal with:

- Minimum 2.6s text hold (existing explicit skip gesture can shorten this).
- Keep requesting and playing the same video, muted, behind the opening.
- Require the current video's PLAYING state and advancing playback time for
  at least 800ms. Coarse YouTube time updates up to 600ms apart are tolerated.
- Then fade for 1.6s before showing START. Buffering during fade cancels removal.
- After 12s without playback, keep the opening and offer a muted retry. A late
  successful load can recover automatically. START still only unlocks audio on
  the same video; it does not become the first video-load gate.
- Keep the separate existing promo-mode entry, filters, shuffle, DIG, tracking,
  submissions, songs and layout unchanged. Retry copy appears only on failure.
